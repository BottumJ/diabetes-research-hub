Calibration

Are the probabilities honest? Each resolved bin plots mean predicted probability against the observed frequency of "true." On the dashed 45° line, confidence matches reality. Above it = underconfident; below = overconfident.

Why this chart and not a number. A single Brier score hides direction of error. The calibration curve shows whether the analyst is systematically over- or under-confident — the signal that feeds back into the doctrine (charter §5). It starts empty by design: the system is built to be scored, and the empty frame is the honest state until trials read out.

PRED-2026-002 NCT07222137 ↗
BRONZE [Guessing] cure relevance: HIGH
Eli Lilly baricitinib (LY3009104) (Phase 3, delay of Stage 3 T1D in at-risk individuals)
“Trial meets its primary endpoint (delay / prevention of progression to Stage 3 T1D).”
P(true) at prediction
0.50
LOCKED 2026-09-30

REFINED 2026-06-23 after pulling BANDIT (Waibel et al., NEJM 2023; n=91, 2:1 randomization, new-onset T1D). BANDIT met its primary: median MMTT-stimulated C-peptide 0.65 vs 0.43 nmol/L/min (P=0.001); C-peptide decline 4.2% vs 29.9% over 48 weeks. That is a strong, significant beta-cell-preservation effect POST-diagnosis (Stage 3 already established). PRED-002 asks the harder, different question: does baricitinib DELAY clinical onset (progression to Stage 3) in PRE-symptomatic at-risk individuals? Three reasons to stay near coin-flip: (1) function-preservation does not cleanly translate to onset-delay across disease stage; (2) n=150 over ~5 years is modest power for a time-to-event endpoint; (3) the prevention field's only clear precedent is teplizumab (delayed onset ~2 yr), which proves the endpoint is winnable but does not generalize to a JAK inhibitor. Net: informed near-coin-flip with a slight positive tilt from the strong mechanistic signal. Not [Likely] because the decisive unknown (cross-stage translation) is unresolved.

Readout: ClinicalTrials.gov primary completion 2031-07 (estimated). FIVE-YEAR horizon - this prediction will not contribute to near-term calibration. Confirm before locking.

Endpoint / provenance: REGISTRY-CONFIRMED 2026-06-23 (ClinicalTrials.gov API v2). Primary: 'Time from Baseline to Diagnosis of Stage 3 Type 1 Diabetes', time frame baseline up to ~5 years. n=150, start 2026-01-12. Claim maps directly to this primary.

Before lock: Probability refined to 0.50 [Guessing] using BANDIT. Decide lock date given 2031 readout; consider whether a 5-year bet is worth a ledger slot now.

Governance

  • Pre-registration. A prediction counts only after locked_date is set, BEFORE any readout. A prediction edited after a readout is void (charter sec 5).
  • Evidence levels. BRONZE (single source) -> SILVER (independently confirmed) -> GOLD (triangulated/replicated).
  • Provenance. Every prediction traces to an NCT id, a claim that matches the trial's REGISTERED primary endpoint, and a source span/URL.
  • To lock a prediction: python Analysis/Scripts/resolve_predictions.py --lock PRED-2026-001 --date YYYY-MM-DD
  • To resolve after a readout: python Analysis/Scripts/resolve_predictions.py --resolve PRED-2026-001 --outcome TRUE
